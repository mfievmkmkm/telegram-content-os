# Telegram Content OS

AI-редакция для `@LigaProgress` и `@GiftsIntelligence`: ищет темы, не повторяет источники,
проверяет силу первого экрана, отправляет черновики администратору и публикует по расписанию.
Публичный текст не содержит служебных ссылок на источники, использует Telegram HTML-разметку,
уместные эмодзи и, когда исходная статья предоставляет изображение, прикладывает его без затрат
на отдельную генерацию картинок.

## Первый запуск

1. Скопировать имена переменных из `.env.example` в Railway.
2. Добавить бота администратором в оба канала.
3. Выполнить `supabase_schema.sql` в Supabase SQL Editor.
4. После деплоя отправить боту `/start` от `@skillell`.
5. Оставить `AUTO_PUBLISH=false`, пока не будет принято минимум 30 материалов на канал.

Перед деплоем: `python -m pytest -q`. В репозитории также настроен GitHub Actions,
который проверяет тесты и компиляцию на каждом push.

Для постоянной базы задайте `SUPABASE_URL` и service-role `SUPABASE_KEY`. Таблицы используют
префикс `content_os_` и не пересекаются с таблицами других ботов. При пустых переменных проект
автоматически использует локальную SQLite как резервный режим.

Команды: `/generate`, `/status`.

`/sync` импортирует последние публичные посты `@LigaProgress`, `@prrlig`,
`@GiftsIntelligence` и `@leanhustle_crypto`. Собственные каналы используются как примеры стиля.
Сторонний канал используется только как радар тем: его текст не передаётся модели для имитации.
Дополнительные радары: `@FootballTrain14`, `@instinctxfootball` и `@getSendGifts`.

Интернет-радар собирает русские и английские материалы из Google News, официальных ресурсов
FIFA, UEFA, Telegram и TON, блога «Неизвестный футбол», а также релизов профильных GitHub-проектов.
Темы ранжируются по свежести, доверию к источнику, релевантности, практической ценности и
наличию потенциального конфликта. Генератор получает верхний ещё не использованный материал.

`/giftpost` создаёт публикацию из фактического рыночного среза Gift Asset: greed/health index,
объёмы и активность атрибутов. При настройке `GIFTS_SUPABASE_*` добавляются последние сигналы
собственного анализатора. Если данные недоступны, бот не придумывает цены и не выдаёт обычный
текст за торговый сигнал.

`/analytics` через необязательный MTProto-коннектор обновляет просмотры, реакции и пересылки
опубликованных постов и показывает рейтинг по engagement rate. Для него нужны
`TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `TELEGRAM_SESSION_STRING`; это секреты Railway.
Обычный Bot API не умеет повторно читать актуальную статистику старых сообщений.

Кнопка `⏰ Выбрать время` показывает ближайшие слоты или принимает точное время в формате
`ДД.ММ ЧЧ:ММ`. Кнопка `🎬 Shorts` создаёт JSON-пакет с хуком, озвучкой, сценами, надписями,
музыкой и CTA. При заданном `MPT_WEBHOOK_URL` пакет автоматически уходит в адаптер
MoneyPrinterTurbo; без него JSON присылается администратору для ручного запуска.

## Принцип редакции

Каждый материал проходит hook-gate. Если первая строка банальная или не содержит конфликта,
боли, неожиданности либо конкретного обещания, LLM автоматически переписывает пост до показа
администратору. Факты и цифры запрещено придумывать.

## Этапы

- Сейчас: два канала, RSS/Atom, дедупликация, hook-gate, ручное согласование, расписание.
- Далее: импорт прошлых постов и style fingerprint.
- Затем: Shorts-пакет и интеграция MoneyPrinterTurbo.
- После: реальные Gifts-данные, аналитика результатов и магазин услуг.
